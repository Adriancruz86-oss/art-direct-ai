A character sheet tells you who the character is.

**Model pages tell you what the finished book looks like when everything is working together.**

# PAGE 45 — CHILDREN'S BOOK PRINT GUIDE

# KNOW THE TERMS.
## VERIFY THE NUMBERS.

**TRIM**  
The final physical page size after manufacturing.

**BLEED**  
Artwork intentionally extending beyond trim so manufacturing shifts do not expose an unwanted white edge.

**SAFE AREA**  
The region where important text and critical visual information stay comfortably away from trim and binding risk.

**GUTTER / BINDING**  
The inside edge behaves differently depending on binding, page count, paper, and manufacturing method. Protect faces, text, and story-critical details.

**RESOLUTION**  
Judge source artwork at its final printed size. Upscaling a small image does not restore detail that was never there.

**COLOR**  
Do not assume every print workflow requires the same color mode or profile. Follow the destination's current instructions.

**PDF + FONTS**  
Verify accepted PDF standard, font handling, transparency, bleed-box, and crop-mark requirements.

## THE RULE

> **Common print practice is guidance. Your printer's current specification is the requirement.**

Save the current printer template/specification with the project and preflight against the same rules you designed for.

### TECHNICAL NOTE
No universal bleed, safe-zone, color-profile, PDF-standard, or crop-mark number is printed here intentionally. Platform-specific figures must be verified from current official documentation before final publication.

# PAGE 46 — STOP DOING THIS / DO THIS INSTEAD

# THE FAST VERSION

**STOP:** "Make it beautiful."  
**DO:** Decide what deserves attention.

**STOP:** Rendering every surface.  
**DO:** Give the page a detail budget.

**STOP:** Asking only for a style label.  
**DO:** Describe how the medium behaves.

**STOP:** Designing characters page by page.  
**DO:** Lock identity before page one.

**STOP:** Comparing only the face.  
**DO:** Check the whole identity system.

**STOP:** Finding room for words afterward.  
**DO:** Compose the text space from the beginning.

**STOP:** Making every page a polished full scene.  
**DO:** Vary distance, density, scale, and quiet.

**STOP:** Regenerating because one thing broke.  
**DO:** Repair the smallest useful area.

**STOP:** Adding action because static feels boring.  
**DO:** Use composition for variety when movement doesn't matter.

**STOP:** Saying "don't make it look AI."  
**DO:** Name the visual behaviors your book refuses.

**STOP:** Approving an image because it is impressive.  
**DO:** Ask whether it serves the book.

# PAGE 47 — FROM IDEA TO FINISHED ILLUSTRATION

# SIX STOPS. ONE CONTROLLED PATH.

## 1 — CLEAR IDEA
What must the reader understand or feel?

**Output:** one visual intention.

→

## 2 — DETAILED DIRECTION
Subject · action · composition · character locks · medium · detail · mood · restraint

**Output:** a directed prompt.

→

## 3 — GENERATE & REVIEW
Compare with manuscript, references, model pages, and neighbors.

> The image fails because ________.

**Output:** an approval or a diagnosis.

→

## 4 — REFINE & ITERATE
Change the responsible variable. Repair locally when possible.

**Output:** controlled revision.

→

## 5 — FINALIZE & PREPARE
Check story, character, style, composition, text space, and defects.

**Output:** approved illustration asset.

→

## 6 — ADD TO YOUR BOOK
Typeset normally. Check sequence, trim, gutter, and production requirements.

**Output:** a book page — not merely an image.

## DON'T AUTOMATICALLY RETURN TO STEP ONE

Character drift? Return to references.  
Crowded page? Return to composition/detail.  
Style drift? Return to visual language.  
Broken hand? Repair the hand.
