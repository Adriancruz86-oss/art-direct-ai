# Art Direct AI — Editing Pass 1
## Structural Audit: Keep / Fix / Cut / Merge

Working source: `AI_Childrens_Book_Illustration_Guide_WORKING_ASSEMBLY_v1.pdf`
Audit basis: 33 assembled source spreads, reviewed as one product.
Goal: reduce repetition, improve pacing, and identify which spreads earn a place before typography/art cleanup.

### Status key
- **KEEP** — concept and spread earn a place; later typography/visual cleanup still expected.
- **FIX** — keep the lesson, but the spread needs meaningful redesign or art correction.
- **MERGE** — useful content duplicates another spread; combine the strongest material.
- **CUT** — does not add enough unique value to justify space.

## Immediate structural decisions

### Definite cuts
- #5 crowded three-way comparison
- #26 second page-turn before/after example
- #27 dense three-example prompt workflow spread

### Merge clusters

**Character / consistency cluster**
- #7, #10, #11, #16, #20, #23, #31
- Final target: roughly 3–4 spreads total:
  1. character identity + immutable/flexible features,
  2. reference-sheet worked example,
  3. drift diagnosis/repair,
  4. printable consistency checklist.

**Detail / restraint cluster**
- #6, #8, #9, #13, #14
- Final target: keep Background, Fabric, Face; merge the broad “overall detail” philosophy into their intro instead of another full spread.

**Print / layout production cluster**
- #15, #18, #22, #29, #30
- Final target: composition lesson, gutter/two-page spread lesson, final production checklist, one detachable print reference sheet. Avoid repeating the same trim/bleed diagram three times.

**Page-turn cluster**
- #24, #25, #26
- Final target: theory + one strong before/after worked example. Cut the second worked example.

## Pacing target after structural cut

Expected result after merges/cuts: approximately **23–26 source spreads**, which should become roughly **44–50 finished single pages** depending on final split and layout.

Recommended rhythm:
1. Hook/problem
2. Philosophy: art direction and restraint
3. AI fingerprints
4. Character/reference system
5. Page composition and pacing
6. Drift/editing
7. Page turns
8. Full worked prompt example
9. Production/preflight tools
10. Cheat sheet
11. Workflow map
12. Quiet closing page

## Next audit pass
Pass 2 should inspect only the retained/fix spreads for:
- anatomy errors or ambiguous limbs,
- faux book seams,
- bad crops,
- over-polished “good” examples,
- skies/backgrounds that violate restraint,
- character drift within teaching examples,
- generated text errors,
- duplicated/incorrect icons or labels,
- layout density inconsistent with the lesson,
- bleed/gutter/text-safe contradictions.
