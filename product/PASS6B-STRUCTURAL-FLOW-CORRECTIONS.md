# Art Direct AI — Pass 6B Structural / Flow Corrections
Date: 2026-09-05

## 1. Add a persistent section/navigation cue
Problem: editorial principle pages and illustrated teaching spreads can feel like separate books.

Fix:
- Add one thin top rule/header accent to EVERY editorial page and every rebuilt illustrated spread.
- Accent color stays consistent within a section.
- Use the same small section label in the upper-left.
- Do not add a heavy chapter banner or dashboard chrome.
- Illustrated spreads keep their art; the navigation cue should sit in existing paper margin / rebuilt text zone, never over important illustration.

Proposed section colors:
- Opening / diagnosis: muted blue
- Restraint / detail: muted ochre
- Character system: muted rose
- Composition / pacing: muted blue-green
- Iteration: muted green
- Prompting: muted violet
- Production / reference: muted ochre
- Closing workflow: muted blue

Goal: a reader should always know which part of the guide they are in without losing the book-like feel.

## 2. Landscape spread treatment
Problem: some source spreads still read as an open-book mockup sitting inside a landscape canvas, leaving weak side margins.

Fix hierarchy:
1. Never chop approved spreads into arbitrary panels.
2. Where the source spread itself is already 3:2 and fills 12×8 well, keep it intact.
3. Where faux book borders / edge thickness / center shadows create dead margin:
   - remove or mask only the mockup border/effect;
   - extend the underlying paper tone to the page edge;
   - preserve illustration composition and all teaching panels;
   - do NOT crop into the actual illustration.
4. Where a spread can be cleanly rebuilt as a true flat landscape page using the same illustration assets, rebuild the layout instead of retaining a photographed-book frame.

No visible crop marks, white seams, paper-edge slivers, or old render fragments may remain behind re-typeset blocks.

## 3. Digital-first product architecture
This guide is DIGITAL-FIRST.

Main production chapter should prioritize:
- resolution / effective image size;
- clean exports;
- file naming / organization;
- working with PNG/JPG/PDF;
- layout and typography;
- proofing on phone/tablet/desktop;
- avoiding rasterized text;
- preserving editable type;
- page sequence / aspect ratio consistency.

Move print-only material out of the main flow:
- bleed;
- trim;
- CMYK / printer color profiles;
- crop marks;
- binding/gutter manufacturing requirements.

New placement:
### Appendix — If You Ever Go to Print
A compact 1–2 page appendix only.
Governing note: printer/platform requirements must be checked against current official specifications.

The existing production checklist is retained but rewritten digital-first.

## 4. Lock background + text colors
Final text-page palette:
- Paper: #F6F0E4
- Primary navy: #172447
- Secondary gray: #5D6470

No slightly different beige or navy on new editorial pages.
Rebuilt illustrated-spread text should use the same navy whenever it does not conflict with the original art.

## 5. Standardize Key Takeaway treatment
One system only:
- pale blue horizontal band;
- same height across landscape pages whenever feasible;
- "Key Takeaway" at left in bold serif;
- takeaway sentence beside it;
- optional 2–3 short check items at right;
- never multiple competing takeaway-box styles.

Do not add a takeaway band if the page is intentionally quiet and the lesson already lands cleanly.

## 6. Comparison spread alignment
For all Before/After / Too Much/Just Right / Good/Bad spreads:
- visual panels matched to exact same displayed width/height when the comparison is intended to be fair;
- top edges aligned;
- caption baselines aligned;
- same amount of surrounding whitespace;
- no panel should win merely because it is larger.

This applies to background, fabric, face rendering, character drift, prompt comparison, and page-turn examples.
