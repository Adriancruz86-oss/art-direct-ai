# Asset risks found in Pass 5

## Risk A — approved replacements are not necessarily inside the 33-spread source comp
The source comp predates some repair generations. The editorial record clearly marks several replacements approved, but a single persistent image-file manifest for those repaired assets is not yet present.

Action before PDF assembly:
- locate persistent approved replacement image files in Library/conversation assets/repo;
- if found, record exact file IDs/paths;
- if absent, stop and recover the original approved asset rather than regenerate blindly.

## Risk B — source-comp numbering is conceptual, not final page numbering
Do not confuse SRC #N with final 48-page numbers.

## Risk C — generated text inside retained art
Any source image containing labels, captions, measurements, signage, or checklist copy must be cropped/cleaned so final text is typeset normally.

## Risk D — fake physical-book presentation
Remove faux seams, page curls, center shadows, photographed-book borders, and mockup effects unless the seam/gutter itself is the explicit instructional subject.

## Risk E — character drift while harvesting
When mixing art from multiple source lessons, prefer the canonical simplified boy/dog. Do not accidentally assemble a "good" page from visibly different character variants.
