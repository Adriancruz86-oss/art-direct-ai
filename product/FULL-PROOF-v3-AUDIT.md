# Priority issues

## PRIORITY 1 — Rasterized text on generated spreads remains the biggest quality gap
Affected: essentially every intact generated spread, most obvious on pages 6, 8, 10, 12, 14, 16, 18, 20, 23, 25, 27, 29–30, 32, 34, 39, 44.

The editorial pages are crisp and readable. The generated-spread text is visibly smaller and softer, especially on phone.

Recommendation:
- Keep each spread composition intact.
- Rebuild the WHOLE spread when we address its typography.
- Do not patch little text rectangles on top.
- Recreate the complete flat landscape layout using the original spread as reference and reuse the full illustration panels/assets where possible.
- This should be a dedicated final-production pass after layout/rhythm is locked.

Do not attempt more partial overlays.

## PRIORITY 2 — Several intact spreads are still too dense at phone scale
The worst offenders are:
- page 14 — Power of a Quiet Page
- page 16 — Character Reference Sheet Example
- page 20 — Character Reference Checklist
- page 23 — Page Composition
- page 27 — Two-Page Spreads & Gutter
- page 29 — Page Turn theory
- page 32 — Fix It in Editing
- page 44 — Print Guide

These are not all bad lessons. The issue is micro-text density.

Recommendation:
- Do not crop them.
- Either keep them as "zoomable reference sheets" intentionally, OR rebuild the whole spread later with larger type and fewer micro-panels.
- Priority rebuilds: 14, 16, 20, 23, 27.
- 44 can remain appendix/reference and tolerate higher density.

## PRIORITY 3 — Page 2 works better as interior poster than as structural page, but needs intentional labeling
Page 2 is the landscape poster and visually jumps away from the clean title page.

Recommendation:
- Keep it.
- Treat it as a deliberate "problem statement poster" after title.
- Consider a tiny editorial footer or facing lead-in rather than trying to normalize it.

## PRIORITY 4 — Section navigation cue is only on editorial pages
Editorial pages use the thin colored top rule; generated spreads do not.

Recommendation:
- Add the same thin section-color rule to intact spreads ONLY if it can sit outside the original spread without covering art.
- If adding it would shrink or alter a spread, skip the rule on that page.
- Consistency is useful, but preserving the spread wins.

## PRIORITY 5 — Print appendix still contains old print-first generated copy
Pages 43–44 correctly demote print, but page 44 itself still contains the old generated print guide with small text and platform-specific language.

Recommendation:
- Keep page 43 as appendix intro.
- Rebuild page 44 later as a crisp 1-page "If You Ever Go to Print" reference using verified, platform-neutral language.
- Do not preserve CMYK/bleed/export claims merely because they exist in the source image.
