# 27 — Build Model Pages

A reference sheet tells you who the character is.

A model page tells you what the **book** looks like when everything is working together.

Choose two or three finished illustrations that best represent the visual language you want to preserve.

Useful model pages might include:

- one clear character view;
- one environment;
- one quiet page;
- one page with the recurring companion;
- one page showing the normal amount of detail and finish.

You do not need a model page for every possible situation.

You need enough examples to answer:

> **Does this new page belong in the same book?**

## Compare the whole page

Check more than the character.

Compare:

- paper/surface behavior;
- pencil and paint marks;
- color intensity;
- facial rendering;
- hair detail;
- clothing detail;
- background density;
- amount of raw paper;
- camera behavior;
- emotional intensity.

A new illustration can match the character perfectly and still look as though a different illustrator took over.

## Use neighboring pages too

Before approving a page, view it beside the page before and after it.

Ask:

- Is one suddenly much more polished?
- Did the palette become dramatically richer?
- Did the character grow or shrink?
- Are three pages using nearly the same composition?
- Did a quiet sequence suddenly acquire cinematic lighting?
- Is the new page much busier than the story beat deserves?

Consistency is not sameness.

The goal is shared visual ancestry.

# 28 — Final Illustration Check

Before an illustration enters the book, stop generating and inspect it.

## STORY
[ ] The physical action matches the manuscript  
[ ] The emotional intensity is appropriate  
[ ] Important props/details are correct  
[ ] The image does not reveal information too early

## CHARACTER
[ ] Identity matches canonical reference  
[ ] Age and proportions match  
[ ] Hair silhouette matches  
[ ] Clothing/shoes/anchors match  
[ ] Companion design and markings match

## STYLE
[ ] Medium and surface match model pages  
[ ] Face is not over-rendered  
[ ] Hair stays under the detail ceiling  
[ ] Clothing has not gained unnecessary texture/pattern  
[ ] Background does not compete with the story  
[ ] Empty paper remains where intended  
[ ] No unrequested glow, rim light or decorative effects

## PAGE
[ ] Focal point is clear  
[ ] Camera distance supports the sequence  
[ ] Text has intentional space  
[ ] Important content is not endangered by trim/gutter  
[ ] Page works beside its neighbors

## DEFECTS
[ ] Hands/feet/limbs read correctly  
[ ] No merged or duplicated objects  
[ ] No accidental symbols or nonsense marks  
[ ] No malformed text baked into the illustration  
[ ] No local defect that should be repaired before layout

### Final question

> **Am I approving this because it serves the book, or because it is impressive by itself?**

If it only wins as a standalone image, look again.

# 29 — Production Checklist

Once the art is approved, production becomes less glamorous and more important.

Do not discover at export that text sits outside the safe area, a face crosses a binding danger zone, or your printer expects a different file setup.

## BEFORE FINAL LAYOUT
[ ] Final trim size chosen  
[ ] Intended printer/platform chosen or shortlist established  
[ ] Current printer specifications downloaded/checked  
[ ] Page count and binding type confirmed  
[ ] Bleed requirements confirmed for this product  
[ ] Safe-area guidance confirmed  
[ ] Gutter/binding behavior understood  
[ ] Image resolution requirements confirmed  
[ ] Accepted color mode/profile confirmed  
[ ] Accepted PDF/export standard confirmed

## DURING LAYOUT
[ ] Pages built at the correct dimensions  
[ ] Bleed extended only where required  
[ ] Important text and faces remain safely inside trim  
[ ] Critical content stays away from binding risk  
[ ] Typography is real/editable — not generated image text  
[ ] Font licensing/embedding requirements checked  
[ ] Page numbers and chapter numbering are correct  
[ ] Full-spread art aligns correctly across pages  
[ ] No accidental fake seams, mockup shadows or page curls remain

## ART PREFLIGHT
[ ] Every recurring character passes consistency check  
[ ] Local anatomy/artifact repairs completed  
[ ] No placeholder/generated gibberish remains  
[ ] No unintended low-resolution assets  
[ ] No accidental crops  
[ ] Model pages still match the final sequence

## EXPORT + PROOF
[ ] Export settings match the current printer/platform specification  
[ ] Fonts handled as required  
[ ] Image quality preserved  
[ ] Bleed/crop marks included only if required  
[ ] Exported PDF inspected page by page  
[ ] Spread transitions checked  
[ ] Physical proof ordered when practical before a larger print run

The final authority is always the current specification for the printer, binding and product you are actually using.

# 30 — Children's Book Print Guide

This reference sheet should teach concepts without pretending every printer uses identical numbers.

## TRIM

**Trim size** is the final physical page size after manufacturing.

Choose the intended product size before final page layout.

Do not assume a dimension from another book, template or platform applies to yours.

## BLEED

**Bleed** is artwork intentionally extended beyond the trim edge so small manufacturing shifts do not expose an unwanted white edge.

Not every page element should bleed.

If an image is meant to reach the edge, extend it according to your printer's specification.

Never invent a universal bleed number in the guide without identifying the printer/platform it applies to.

## SAFE AREA

The safe area is the region where important text and critical visual information are kept comfortably away from trim and binding risk.

There is no single universal safe-zone value for every format.

Use the printer's current template/specification.

And even when something is technically inside the allowed area, give important text enough breathing room to look intentional.

## GUTTER / BINDING

The inside edge of a page behaves differently depending on binding, page count, paper and manufacturing method.

Avoid placing small critical details directly at the center.

For a two-page illustration, design across the spread while protecting faces, text and story-critical objects.

## RESOLUTION

High-resolution source artwork is important for print, but do not treat "300 DPI" as a magic number detached from final physical size.

Check the printer's required/recommended effective resolution at the size the image will actually be printed.

Upscaling a tiny image does not restore detail that was never there.

## COLOR

Printers and print-on-demand platforms do not all request color files in the same way.

Some workflows accept or prefer RGB and perform conversion.

Others specify particular CMYK profiles or production standards.

Follow the current instructions for the destination rather than converting automatically because "print means CMYK."

## PDF + FONTS

Check:

- accepted PDF standard;
- font embedding requirements;
- transparency handling;
- crop-mark requirements;
- bleed-box requirements;
- whether the platform supplies a template or preflight tool.

Do not add crop marks simply because a design application offers the option.

Add them only when the production workflow requests them.

## The rule worth remembering

> **Common print practice is guidance. Your printer's current specification is the requirement.**

Save the current template/specification with the project so you can verify the final file against the same rules you designed for.
