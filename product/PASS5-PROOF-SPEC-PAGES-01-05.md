# Art Direct AI — First Proof Build Specification
## Pages 1–5
Date: 2026-09-05
Status: ready for fixed-layout assembly

This document converts Pass 4 copy + Pass 5 grid rules into exact page-level composition instructions.

## Global page rules for proof
- Flat page, warm off-white paper.
- Editorial serif headline; readable serif body.
- Dark navy/near-black type.
- No generated typography.
- No rounded UI cards.
- No drop shadows.
- No faux gutter/page curl.
- Accent colors muted and sparse.
- Preserve at least one substantial untouched-paper field per page.

# PAGE 1 — TITLE

### Composition
Top-left title block occupying roughly upper 35–40%.

ART DIRECT AI

Children's-Book Illustration Without the Default AI Look

A practical guide to restraint, consistency, composition, prompting, and visual decision-making

Lower-right/lower-third:
one small canonical boy-and-dog spot illustration only.

### Visual balance
Do not center everything.
Do not add a decorative frame.
The paper itself is part of the cover/interior-title design.

Harvest canonical boy/dog from existing approved material.

# PAGE 2 — HOW TO USE THIS GUIDE

### Headline
DON'T COPY A STYLE.
BUILD A VISUAL LANGUAGE.

### Layout
Left 55–60%: short editorial text.
Right/lower-right: a few loose mark/texture samples, not a character scene.

Five controls appear as typographic subheads in the text flow:
RESTRAINT / CHARACTER / PAGE DESIGN / ITERATION / DIRECTION

Do not place them in five equal cards.

### Visual-language sample
Set the example language as one quiet line:
warm paper · graphite · colored pencil · light wash · sparse faces · simplified hair · plain clothing · unfinished areas

Finish with:
The point is not to copy that look.
The point is to see how rules create a look.

# PAGE 3 — AI ISN'T THE PROBLEM. DEFAULT AI IS.

### Layout
Illustration should dominate roughly 55–60% of the page.

Use source-comp #1 art as the problem visual.
Crop away generated chapter text/captions wherever practical.

Text occupies one quiet block, not multiple callouts.

### Hierarchy
Small kicker:
STOP MAKING AI-LOOKING CHILDREN'S BOOKS

Main:
AI ISN'T THE PROBLEM.
DEFAULT AI IS.

Body trimmed exactly to Pass 4.

Pull quote:
Don't ask the model to make the best image it can. Ask it to make the image your book needs.

### QA
At final size inspect hands/faces only. Do not repair microscopic weirdness nobody will see in print.

# PAGE 4 — WHY EVERYONE GETS THE SAME LOOK

### Main
YOU ASKED FOR A SCENE.
THE MODEL MADE THE REST OF THE DECISIONS.

### Layout
One dominant source-comp #2 problem visual.

Remove/crop/cover any generated signage or embedded text and replace required wording with normal typography.

The undecided variables run as a short editorial list beside/below the image.

The four-line rhythm:
Too much finish.
Too much detail.
Too much lighting.
Too much decoration.

should be large enough to function as a visual beat, not another bullet list.

Bottom question:
What decisions would annoy me if the model made them for me?

Those decisions belong in your direction.

### QA
Crowd/secondary figures must not become the focal point.
If embedded generated text cannot be removed cleanly, crop tighter rather than rebuilding the illustration.

# PAGE 5 — YOU'RE THE ART DIRECTOR NOW

### Main
A PROMPT NAMES THE SCENE.
ART DIRECTION CONTROLS WHAT IT BECOMES.

### Layout
Use one restrained dock illustration, preferably a canonical boy/dog result already approved.

Illustration occupies lower/right portion and fades into paper where possible.

Manuscript beat appears as a small italic quotation:
A boy and his dog sit at the end of a dock at sunset.

Five decisions are set as margin notes or short typographic blocks:
WHAT MATTERS
WHAT STAYS SIMPLE
WHAT REMAINS EMPTY
WHAT CANNOT DRIFT
WHAT IS PROHIBITED

No boxes around them unless a single subtle rule is needed.

Closing line:
Generate less blindly. Decide more deliberately.

### Purpose
Page 5 must visually demonstrate the difference between a prompt and art direction. It should already feel calmer than page 3.

# Proof checkpoint after pages 1–5

Do not continue the full 48-page build until these five pages prove:
1. title hierarchy;
2. body size/leading;
3. serif/sans relationship;
4. paper tone;
5. illustration crop behavior;
6. caption/pull-quote treatment;
7. page-number placement;
8. accent-color restraint;
9. visual rhythm from dense/problem page to quiet/directed page.

If these five work as a family, reuse the system rather than redesigning later sections.
